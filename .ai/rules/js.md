# Js

## Classify assets before accountability and depreciation
Use the PHP 50,000 acquisition-cost threshold consistently: PHP 50,000 and above is PPE, uses PAR, and is depreciable; below PHP 50,000 is semi-expendable, uses ICS, and is not depreciated. PPE residual value is percentage-based (minimum 5%) with an auditable basis and available-for-use date. Preserve each asset's permanent property_tag_uuid when updating or reseeding.
